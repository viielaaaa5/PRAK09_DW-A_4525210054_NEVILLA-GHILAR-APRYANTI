
# ☕ Selaras Coffee

Selaras Coffee merupakan website Company Profile UMKM yang bergerak di bidang penjualan minuman kopi. Website ini dibuat sebagai tugas individu menggunakan HTML, CSS, dan Bootstrap 5.

Website ini bertujuan untuk memperkenalkan Selaras Coffee kepada calon pelanggan dan mitra bisnis melalui tampilan yang sederhana, modern, dan responsif.

## 📌 Fitur Website

1. **Navbar Responsif**  
   Navigasi website yang dapat digunakan pada desktop maupun perangkat mobile.

2. **Hero Section**  
   Menampilkan halaman utama dengan judul, deskripsi, gambar, dan tombol untuk melihat menu.

3. **Menu Produk**  
   Menampilkan tiga pilihan produk kopi lengkap dengan gambar, deskripsi, dan harga.

4. **Promo Alert**  
   Menampilkan informasi promo atau diskon khusus kepada pelanggan.

5. **Modal**  
   Menampilkan informasi tambahan ketika pengguna menekan tombol Lihat Detail.

6. **Form Kontak**  
   Formulir untuk memasukkan nama, email, subjek, dan pesan.

7. **Footer**  
   Menampilkan nama brand, slogan, dan navigasi tambahan.

8. **Custom CSS**  
   Menggunakan desain warna cokelat, cream, dan putih sebagai identitas visual Selaras Coffee.

## 🛠️ Teknologi yang Digunakan

- HTML5
- CSS3
- Bootstrap 5
- Google Fonts (Poppins)

## 🚀 Cara Menjalankan Website

1. Download atau clone repository ini.
2. Buka folder project menggunakan Visual Studio Code.
3. Pastikan file `index.html` dan `style.css` berada dalam satu folder.
4. Jalankan file `index.html` menggunakan browser.
5. Website siap digunakan.

## 📝 Catatan

Website ini merupakan project frontend untuk memenuhi tugas pembuatan One Page Website menggunakan Bootstrap 5.

Form kontak masih berupa tampilan frontend dan belum terhubung dengan database maupun layanan pengiriman email.
